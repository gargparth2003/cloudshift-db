# Changelog

## 1.1.0 — 2026-11-27

### Added

- Enterprise migration and operations shell with sandbox, verified replay, and live-local truth modes.
- Persistent ten-step migration planner, nine scenario templates, provider/region mapping, JSON exports,
  and deterministic feasibility checks with actionable consequences and remediation.
- Deterministic migration simulation with snapshot/CDC backlog math, capacity controls, bounded events,
  network interruption, mismatch repair, validation, recovery, and guarded cutover.
- Draggable multi-provider architecture builder, CIDR/security playground, transparent editable FinOps
  estimator, SRE/incident scenarios, disaster-recovery planner, and strategy comparison.
- AWS-first secure Terraform artifact generator and configurable Kubernetes manifest explorer.
- Route-specific GitHub Pages artifacts so every documented deep link supports direct successful refresh.
- Five domain tests and ten backend-independent browser acceptance journeys.

### Changed

- The landing page now leads with the cloud migration studio while preserving the v1.0 verified replay.
- The AWS reference exposes storage, retention, Multi-AZ, and deletion-protection decisions; exports database
  logs; enforces TLS-only versioned backup storage; and rejects public-anywhere console ingress.
- CI now gates the deterministic planning domain in addition to type-check, builds, public browser flows,
  backend, fresh Compose integration, infrastructure validation, and secret scanning.

### Evidence boundary

- Cloud plans, simulations, costs, Terraform, Kubernetes, SRE, and DR outputs are modeled or configuration-
  only. No AWS, Azure, or Google Cloud resource was created. v1.0 recorded local measurements remain intact.
